## Projetos em destaque

### ⚽ [brasileirao-ml](https://github.com/MiguelRichena/brasileirao-ml) — previsão do Brasileirão com Machine Learning

Pipeline completo: 5.646 partidas, 32 features causais, validação *walk-forward* por temporada, benchmark contra odds de fechamento e simulação Monte Carlo da tabela. Dashboard em Streamlit e site em React/TypeScript.

O ponto que mais me orgulha não é o resultado — é o que apareceu no caminho: a primeira versão **batia a Pinnacle com +19% de ROI**. Tratei como bug, encontrei a causa (uma feature que usava a posição final da temporada *corrente*), corrigi e escrevi testes que travam o vazamento. Com dados honestos, o modelo fica **~0,03 acima do mercado em log loss** — e o README explica por quê.

`Python` · `scikit-learn` · `Streamlit` · `React` · `TypeScript` · `GitHub Actions`
→ [**Ver o site**](https://miguelrichena.github.io/brasileirao-ml/) · [Código](https://github.com/MiguelRichena/brasileirao-ml)
