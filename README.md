## Featured projects

### ⚽ [brasileirao-ml](https://github.com/MiguelRichena/brasileirao-ml) — Brazilian league prediction with Machine Learning

End-to-end pipeline: 5,646 matches, 32 causal features, season-by-season *walk-forward* validation, benchmark against closing odds and a Monte Carlo title simulation. Streamlit dashboard plus a React/TypeScript site.

What I'm proudest of isn't the score — it's what showed up on the way: the first version **beat Pinnacle with +19% ROI**. I treated it as a bug, found the cause (a feature leaking the *current* season's final standings), fixed it and wrote tests that lock the leak out. With honest data the model lands **~0.03 worse than the market in log loss** — and the README explains why.

`Python` · `scikit-learn` · `Streamlit` · `React` · `TypeScript` · `GitHub Actions`
→ [**Live site**](https://miguelrichena.github.io/brasileirao-ml/) · [Code](https://github.com/MiguelRichena/brasileirao-ml)
